PALETTE STUDIES

Every other option in this pass holds the colour fixed and changes something else — surfaces, tiles, frames, detail, the wordmark. This one changes only colour. Same layout, same fonts, same border geometry, same copy, same numbers, same art. Six variants of one real screen, so the comparison is honest: if the black-and-gold is what reads generated, it has nowhere to hide here.

Hypothesis (a) — the colours are wrong

Near-black plus saturated gold at high contrast on every surface is the default fantasy-UI combination. It reads generated because it is the average of ten thousand generated fantasy UIs.

Hypothesis (b) — the discipline is wrong

Gold currently marks panel borders, panel titles, keys, key labels, stat labels, table headers, quest titles, building plates, the wordmark and the currency — all at once. When everything is special, nothing is.

How to read this page

Each variant renders the same screen: the header with its streak and purse, a sworn quest, Old Fenn's dialogue and two live offers (one road quest, one Rest Writ with omens), a slice of the Hall of Records, the Siege banner, and the town with its real hand-drawn tiles. Copy and numbers are lifted from giver.js, hall.js, town.js and quests.py. Nothing is paraphrased and nothing is invented.

Beside each screen sits its evidence: the surface ramp with its grayscale twin (value structure matters more than hue — two surfaces that collapse to one value stop being two surfaces), measured contrast for the 10–12px hand-drawn glyphs, the eight activity hues and four rarity hues restated, and the full token block ready to paste.

One honest caveat about the specimens. The shipped vignette is position:fixed over the whole viewport; here it is scoped to each specimen so six can share a page. Every specimen carries it equally, so the comparison holds.
